# Portfolio de antenas y simulación electromagnética

Sitio personal publicado con GitHub Pages. Cada proyecto vive en su propio repositorio, con su modelo, sus resultados y las instrucciones para reproducirlo.

## Estructura

- `index.html`: página principal del portfolio.
- `proyectos/array-parches-hfss/`: plantilla del primer proyecto (array de parches en HFSS).

## Cómo publicarlo

1. Crea un repositorio público llamado `tu-usuario.github.io`.
2. Sube todos estos archivos a la rama `main`.
3. En el repositorio, entra en Settings → Pages y elige "Deploy from a branch", rama `main`, carpeta `/ (root)`.
4. Tras unos minutos, la página estará en `https://tu-usuario.github.io`.

Antes de publicar, busca en `index.html` los comentarios `TODO` y cambia `tu-usuario`, el correo y el enlace de LinkedIn por los tuyos.
